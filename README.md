## 🔮 What is Rewind X?

Rewind X introduces a **deterministic, non-custodial undo window** for ERC-20 transfers.

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   SEND ──────► [ 2min-48h SAFETY WINDOW ] ──────► FINALIZE     │
│                        │                                        │
│                        ▼                                        │
│                    REWIND?                                      │
│                   ↺ Cancel                                      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

<br>
